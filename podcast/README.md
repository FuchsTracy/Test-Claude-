# Sechs-Uhr-Briefing

Täglicher 10-Minuten-Podcast zu Weltgeschehen, KI und HR.

- **Player:** https://claude.ai/artifact/UNMyYJRwaEbEjXaRo1Vj4x (Quelle: `player.html`). Liest die Folgen per Sprachausgabe des Browsers vor; Folgen liegen in der Artifact-Datenbank, Collection `episodes`, ein Dokument pro Tag (`YYYY-MM-DD`).
- **Geplante Aufgabe:** täglich 05:40 Uhr (Europe/Berlin), startet eine neue Session mit dem Prompt aus `daily-prompt.md`, recherchiert, schreibt die Folge in die Datenbank und schickt eine Push-Benachrichtigung.
